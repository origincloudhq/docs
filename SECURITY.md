# Security

To report a security vulnerability in Origin Cloud, its documentation or this
site, don't open an issue or a pull request. Use **Report a vulnerability** on
this repository's [Security tab](https://github.com/origincloudhq/docs/security/advisories/new),
which reaches us privately.

Tell us what you found, how to reproduce it, and what it affects. Please give
us a reasonable time to fix it before you disclose it.

A mistake in the documentation that is not a vulnerability, such as a page
describing a security setting wrongly, is welcome as an ordinary issue.
